# Tools Prerequisite Information
In this section, we will cover the prerequisites for some tools and technologies required for the course. Before you begin, you need to set up a few things. We will be working in three main areas in this section:

1. Tools that you need to install on your computer.
2. Accounts that you need to create by signing up on certain websites, which I will guide you through.
3. AWS setup, as we will be using AWS as our cloud computing solution. To use it safely and securely, we will take some necessary steps.

There are a few commands and steps in this section that you may not understand immediately, and that is perfectly fine. We will master them later.

Before we get started with the prerequisites, let's take a look at the GitHub repository where we keep all our source code, scripts, and configuration files. Let's explore that first.

Open your browser and access the following URL:
https://github.com/hkhcoder/vprofile-project

The `vprofile-project` is a GitHub repository that contains the source code for our project, scripts, commands, documents, and many other resources that we will use throughout this course.

A Git repository can have multiple branches. If you click on the branch dropdown, you will see different branch names. Each branch may or may not have different source code or files based on the project or the section we are working on. Based on the section, I will guide you on which branch to select for that particular project or section.

For now, just bookmark this link. Whenever I mention the source code, repository, or `vprofile-repository`, I am referring to this repository. We will also be cloning it to our local machine and working with it extensively.

### Now, let's review what we will be doing in this prerequisite section. We will be working in three areas:
- Tools that we need to install on our laptop or desktop.
- Signups for various accounts.
- AWS prerequisites and setup.

### Let's start with the tools that we will be installing. The essential tools include:

- Oracle VM VirtualBox
- Git Bash
- Vagrant
- Chocolatey (for Windows users) or Brew (for macOS users)
- JDK8
- Maven
- IntelliJ (our Integrated Development Environment). If you prefer another IDE such as Visual - Studio or have any other personal preference, you may use that.
- Sublime Text Editor
- AWS CLI
- Terraform (which we will set up within the project itself)

### In addition to tools, there are a few accounts you need to sign up for:
- GitHub
- A domain registrar account to purchase a domain. I will be using GoDaddy, but you can use any other domain registrar of your choice.
- Docker Hub account to store our Docker images.
- SonarCloud account.

### Regarding AWS, we need to do the following:
- Obtain a free tier AWS account.
- Set up an IAM user with multi-factor authentication.
- Configure a billing alarm.
- Obtain a certificate from AWS, which we will use to set up HTTPS secure connections.

Now, let's get started with the tools first.

## Key Takeaways
- The course requires setting up essential tools, accounts, and AWS configurations before starting.
- The GitHub repository `vprofile-project` contains all source code, scripts, and configuration files needed.
- Key tools to install include Oracle VM VirtualBox, Git Bash, Vagrant, Chocolatey or Brew, JDK8, Maven, IntelliJ or preferred IDE, Sublime Text Editor, AWS CLI, and Terraform.
- Important accounts to create include GitHub, a domain registrar (e.g., GoDaddy), Docker Hub, SonarCloud, and AWS with proper security setups.
