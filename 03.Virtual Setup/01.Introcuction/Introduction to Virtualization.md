# Welcome to Virtualization
Back in my college days, when I was learning Linux, I had to set up my own lab with a minimum of two computers.

I could not afford these computers, so what I did was start purchasing used computer parts such as CPU, RAM, hard disks, cabinets, and monitors over a period of time.

Then, I assembled them together, installed operating systems on them, connected them with Ethernet cables, and started practicing Linux in a server-client setup.

Now, if you need to practice the same thing today with 5, 10, or 15 computers together, it would be very expensive.

Back in those days, I did not know about virtual machines, but now you can very easily download virtual machine software and create virtual machines.

## What is a Virtual Machine?
Inside your computer, there is a virtual computer that you create. You can create one, two, three, or multiple virtual computers inside your physical computer. You can install operating systems on them, connect them together, and start your practice or set up your lab.

That is exactly what we will be doing in this section. We will be creating virtual machines first manually, and then we will be creating virtual machines automatically because we will need this setup to go through the Linux section.

## Key Takeaways
- Virtual machines allow the creation of multiple virtual computers within a single physical computer.
- Setting up physical labs with multiple computers can be expensive and impractical.
- Virtualization software enables easy creation and connection of virtual machines for practice and lab setups.
- The section will cover both manual and automatic creation of virtual machines to support Linux learning.
